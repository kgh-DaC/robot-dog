# 로봇개 대시보드 및 디지털 트윈

변경 전에 기존 웹 앱과 로봇 형상을 확인한다. 적절한 경우 기존 WebSocket/UI 리소스를 활용하되, 프로토타입의 로컬 제어 채널이 안전하다고 가정하거나 현재 보내지 않는 텔레메트리 필드가 있다고 가정하지 않는다.

## 현재 구성과 기능 명세 (먼저 읽기)

- [현재 웹 구성](references/current-web-stack.md): 실제로 쓰는 페이지·펌웨어·게이트웨이 경로, 상태 응답 필드, 페이지 제약(외부 리소스 금지, 한 파일, 내장본 재생성), 바꾸면 안 되는 안전 동작. 페이지를 고치는 모든 작업에서 읽는다.
- [수평 유지 ON/OFF 비교 그래프](references/level-comparison.md): 수평 유지 켜짐·꺼짐 구간의 roll/pitch 비교 그래프와 요약 통계를 만들 때 읽는다.
- [관절 기구학 모형](references/kinematic-model.md): 실제 형태와 닮은 4다리 모형, 순기구학, 모델링 데이터 표를 만들 때 읽는다. 확정되지 않은 관절 방향은 추측하지 말고 사용자에게 확인한다.

페이지를 고친 뒤에는 `python software/robot_control_web/embed_page.py`로 내장본을 다시 만들고, 저장소 루트에서 `python -m unittest discover tests`를 실행한다.

## 실시간 상태 및 디지털 트윈

- 연결 상태, 텔레메트리 경과 시간, 센서 상태·오류, 보행·활성화 상태, MPU9250 기울기, 관절별 각도, INA219 전력·에너지를 단위와 함께 표시한다.
- 합의된 관절 ID, 축 규약, 보정값, 명령된 자세로 모델을 애니메이션한다. 명령 각도는 그 사실을 분명히 표시하고, 피드백 하드웨어가 있을 때만 측정 각도를 보여준다.
- 오래된 값이 실시간 정보처럼 남지 않도록 명확한 오래됨·연결 끊김 상태를 표시한다. 값이 없으면 0이 아니라 알 수 없음으로 취급한다.
- 배터리 용량·충전 상태 추정치는 추정값으로 표시하고 산정 방법이나 보정 상태를 제공한다.

## 인터넷 제어

- 동작 명령은 인증된 게이트웨이/API로만 전송한다. 정적 번들에 비밀 정보나 권한 판단 로직을 넣지 않고, 공용 페이지에서 ESP32 제어 소켓으로 직접 연결하지 않는다.
- 명시적 활성화/비활성화를 요구하고, 명령 수락 여부를 보여준다. 동작 중에도 `STOP`을 눈에 띄고 쉽게 사용할 수 있게 한다.
- 명령 손실·만료·거부와 기기 오류 상태를 반영한다. 브라우저 UI는 장치 측 감시 타이머나 검증을 대체하지 않는다.
- 모의 텔레메트리와 시뮬레이션한 명령 확인 응답으로 테스트하며 자동화된 테스트에서 실물 동작을 유발하지 않는다.

## 검증

반응형 레이아웃, 상태·정지 제어 접근성, 형식 오류·버전 불일치 텔레메트리, 오래됨·연결 끊김·재연결, 12개 관절 전체, 생산자와 소비자의 필드 일치를 확인한다. 기존 프로젝트 스크립트로 빌드하고 레거시 도구체인 제약을 보고한다.
